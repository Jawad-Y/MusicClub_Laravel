# Music Club API Endpoints

Base URL: `http://localhost:8000`

## Authentication
```
POST   /api/login
POST   /api/logout
```

## Users
```
GET    /api/users
POST   /api/users
GET    /api/users/{user}
PUT    /api/users/{user}
PATCH  /api/users/{user}
DELETE /api/users/{user}
```
